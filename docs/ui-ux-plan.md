# UI/UX 與色彩計劃：港鐵下一班車

| 項目 | 內容 |
|---|---|
| 版本 | v0.1 |
| 日期 | 2026-10-22 |

## 1. 已決定的設計方向

| 決定 | 選擇 |
|---|---|
| 車站卡視覺 | **B：中性底色 + 路綫色條**。路綫色只作識別，不作大面積底色 |
| 倒數格式 | **分鐘大字 + 到站時間小字**；少於 1 分鐘顯示「即將抵達」 |
| 深色模式 | **跟隨系統**（`prefers-color-scheme`），不設手動切換 |
| 首頁 | **收藏站班次 + 搜尋列**；沒有收藏時顯示搜尋及「定位最近車站」 |

## 2. 設計原則

1. **一眼看懂。** 用戶多數在趕車。每張卡最大的字是倒數分鐘，其次是目的地，再其次是月台。
2. **顏色不是唯一線索。** 路綫色旁邊一定有路綫名或代號；延誤狀態一定有文字。
3. **路綫色與狀態色分開。** 十條路綫已用盡大部分色相，所以狀態（延誤、過時、錯誤）用獨立的語意色，並且一定配圖示及文字。
4. **單手可用。** 主要操作放在畫面下半部；可點擊範圍最少 44 × 44px。
5. **不假裝精準。** API 是估算，所以只顯示到分鐘，不跳秒。

## 3. 資訊架構

```
首頁
├─ 搜尋列（常駐頂部）──> 搜尋結果 ──> 車站頁
├─ 收藏站（每站一張車站卡，直接顯示班次）
├─ 「定位最近車站」按鈕 ──> 最近 3 個站 ──> 車站頁
└─ 「按路綫瀏覽」──> 路綫列表 ──> 車站列表（路綫圖形式）──> 車站頁

車站頁
├─ 站名、收藏星號
├─ 路綫分頁（轉車站才出現，例如金鐘：TWL / ISL / SIL）
└─ 每個方向一組班次（總站只有一組）
```

頁尾（每頁）：「資料來源：DATA.GOV.HK · 本 App 與港鐵公司無關」及中／EN 切換。

## 4. 畫面規格

### 4.1 首頁

| 狀態 | 顯示 |
|---|---|
| 有收藏 | 搜尋列 → 收藏站車站卡（按加入次序，可拖動排序屬 stretch）→ 「按路綫瀏覽」連結 |
| 沒有收藏（第一次使用） | 搜尋列 → 歡迎提示「收藏常用車站，下次一開就見到班次」→ 「定位最近車站」及「按路綫瀏覽」兩個按鈕 |

### 4.2 搜尋

- 輸入即篩選，不需要按搜尋鍵。
- 可以用中文名、英文名、站代號搜尋（「將軍」、「tseung」、「TKO」）。
- 結果每行：站名 + 該站所有路綫的色塊徽章。
- 沒有結果時顯示：「找不到『xxx』。試試英文名或車站代號。」

### 4.3 路綫瀏覽

- 路綫列表：每行一個路綫色徽章 + 路綫全名，按官方次序排列。
- 車站列表：一條垂直路綫色線，車站為線上的圓點，轉車站用空心圓並列出其他路綫徽章。

### 4.4 車站頁及車站卡（B 方向）

```
┌──────────────────────────────┐
│ [TKL] 將軍澳              ☆  │  ← 徽章 + 站名 18px/500 + 收藏
│                              │
│ ┃ 往 寶琳 · 1 號月台          │  ← 方向標題 13px，次要文字色
│ ┃ 寶琳            1 分        │  ← 倒數 24px/500，等寬數字
│ ┃                 10:58      │  ← 到站時間 12px
│ ┃ 康城            3 分        │  ← 第 2–4 班 16px，次要文字色
│                              │
│ ┃ 往 北角 · 2 號月台          │
│ ┃ 北角            2 分        │
│                              │
│ 15 秒前更新                   │  ← 12px，過時時轉警告色
└──────────────────────────────┘
  ┃ = 3px 路綫色條（無圓角）
```

- 每個方向最多顯示 4 班；第 1 班最大，其餘縮細。
- 轉車站：卡頂加路綫分頁，分頁底線用該路綫色。
- 收藏站在首頁的卡片顯示同樣內容，但每個方向只顯示頭 2 班，點擊進入車站頁。

## 5. 色彩系統

### 5.1 中性色（介面主體）

| Token | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#F6F7F9` | `#111216` | 頁面底色 |
| `--surface` | `#FFFFFF` | `#1C1D23` | 卡片 |
| `--border` | `#E3E5E8` | `#2E3038` | 分隔線 |
| `--text` | `#1F2328` | `#F3F4F6` | 主要文字 |
| `--text-secondary` | `#5B616B` | `#A7ADB5` | 次要文字 |
| `--accent` | `#1E6BE2` | `#5B9DFF` | 連結、焦點框、主要按鈕（全 App 只此一個強調色）。淺色原本用 `#1F6FEB`，放在頁面底色上只有 4.32:1，M3 調深 |
| `--on-accent` | `#FFFFFF` | `#111216` | 主要按鈕上的文字 |

已計算的對比度：主要文字 15.8（淺）/ 15.3（深）；次要文字 6.2 / 7.4；強調色 4.6 / 6.2。全部 ≥ 4.5:1。

### 5.2 狀態色

| 狀態 | 淺色（文字／底） | 深色（文字／底） | 一定配合 |
|---|---|---|---|
| 延誤 | `#9A4D00` / `#FFF4E5` | `#FFB366` / `#3A2610` | 圖示 + 「列車服務延誤」橫幅 |
| 資料過時（超過 45 秒未更新） | `#9A4D00` 文字 | `#FFB366` 文字 | 「1 分鐘前更新 · 重新載入」 |
| 錯誤 | `#B42318` / `#FEF3F2` | `#F97066` / `#3A1715` | 圖示 + 說明 + 重試按鈕 |
| 即將抵達 | 與主要文字同色，字重 500 | 同左 | 文字「即將抵達」，不另加顏色 |

已計算的對比度：延誤 5.6（淺）/ 8.1（深）；錯誤 6.1 / 5.7。全部 ≥ 4.5:1。

**為何「即將抵達」不用綠色：** 綠色已是觀塘綫的顏色，放在班次旁邊會令人誤會成路綫。

### 5.3 路綫色

> 已對照 Wikipedia「Module:Adjacent stations/MTR」核對（2026-10-22），並非港鐵官方來源。對比度已用 WCAG 公式計算。程式碼來源：`src/data/lines.ts`。

| 路綫 | 代號 | 路綫色 | 徽章文字色 | 徽章對比度 |
|---|---|---|---|---|
| 港島綫 | ISL | `#007DC5`（徽章用 `#007BC1`） | 白 | 4.56 |
| 荃灣綫 | TWL | `#ED1D24`（徽章用 `#E81C23`） | 白 | 4.54 |
| 觀塘綫 | KTL | `#00AB4E` | `#111418` | 6.10 |
| 將軍澳綫 | TKL | `#7D499D` | 白 | 6.34 |
| 東涌綫 | TCL | `#F7943E` | `#111418` | 8.14 |
| 機場快綫 | AEL | `#00888A`（徽章用 `#008486`） | 白 | 4.52 |
| 東鐵綫 | EAL | `#53B7E8` | `#111418` | 8.18 |
| 屯馬綫 | TML | `#923011` | 白 | 7.92 |
| 南港島綫 | SIL | `#BAC429` | `#111418` | 9.69 |
| 迪士尼綫 | DRL | `#F173AC` | `#111418` | 6.85 |

**使用規則：**
- **徽章**（路綫代號小方塊）：底用路綫色，字用上表的文字色。全部 ≥ 4.5:1，符合 AA。
- **色條**（車站卡左邊 3px）：純裝飾，旁邊一定有路綫徽章，所以不需要符合 3:1。實測時要注意，淺色模式下 TCL、EAL、SIL、DRL 的色條較淡；深色模式下 TKL、TML 較淡。
- **不用路綫色做大面積底色或文字色。**
- 路綫色在淺色及深色模式下保持不變，令用戶在兩個模式都認得出。

## 6. 字體與排版

- **字體：** 系統字體，不載入網絡字型（保持首次載入 < 2 秒）。
  `system-ui, -apple-system, "PingFang HK", "Microsoft JhengHei", "Noto Sans TC", sans-serif`
- **數字：** 倒數及時間用 `font-variant-numeric: tabular-nums`，更新時不跳位。
- **字級：**

| 用途 | 大小 / 字重 |
|---|---|
| 第 1 班倒數 | 24px / 500 |
| 站名 | 18px / 500 |
| 班次目的地、第 2–4 班倒數 | 16px / 400 |
| 方向標題、月台 | 13px / 400 |
| 到站時間、更新時間、頁尾 | 12px / 400 |

- **字重只用 400 與 500。**
- **間距：** 4px 為基本單位（4 / 8 / 12 / 16 / 24）；頁面左右留 16px。
- **圓角：** 卡片 12px；按鈕、輸入框 8px；徽章 4px。

## 7. 狀態與回饋

| 情況 | 處理 |
|---|---|
| 首次載入 | 骨架卡（灰色塊），不用轉圈 |
| 背景更新 | 數字直接更新，不閃爍；不顯示載入中 |
| 超過 45 秒未成功更新 | 更新時間轉警告色，並提供「重新載入」 |
| API 錯誤 | 保留上一次成功的班次並標示「可能已過時」；完全沒有資料時才顯示錯誤卡 |
| 非服務時間／沒有班次 | 「暫時沒有班次資料。可能是非服務時間。」 |
| 延誤（`isdelay: Y`） | 車站卡頂部警告色橫幅「列車服務延誤」 |
| 定位權限被拒 | 「未能取得位置。你可以用搜尋或按路綫瀏覽。」並顯示兩個按鈕 |
| 收藏／取消收藏 | 星號即時切換，底部短暫提示「已收藏」／「已取消收藏」，可復原 |

## 8. 動效

- 只用 150ms 淡入（新卡片、提示訊息）。
- 支援 `prefers-reduced-motion`：開啟時取消所有動效。
- 不做數字翻牌或倒數動畫。
